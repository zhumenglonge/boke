# 冷水江市志 · 按节阅读与公众号改编

《冷水江市志》1994 版（中国城市出版社，bookId=970702）全文收录于湖南数字方志馆。
正文文字已随详情接口直接返回（OCR 文本），**只取文字，绝不下载 PDF**（该站无整本合并 PDF，分册数百个）。

## 铁律

- **默认不开浏览器**：用户在上班，取数一律用 Node fetch（脚本已内置）。任何浏览器操作必须先征询用户同意。
- 阅读版与公众号版是两个独立文件，公众号改编不得改动阅读版。
- 涉及 1994 年以后的事实（转型、现状、数据），必须先 WebSearch 核实再写，禁止凭记忆。
- 志书数据以原文为准；OCR 存疑处按文意复原，并在文件头来源注里说明。

## 接口要点（脚本已封装，无需手拼）

- BASE：`http://113.246.57.229:8184`
- 目录树：POST `/lzt/bookCatalogue/openTree`，body `{"query":{"bookId":"970702"}}`，返回篇→章→节三级树，每节点有 id。
- 节正文：POST `/lzt/bookCatalogue/openInfo`，body `{"detailId":"<节点id>"}`，`data.content` 即该节 OCR 全文，`data.name` 节名。
- 必带请求头：`authorization: basic enlzb2Z0Onp5c29mdCo2MDc5`、`u-terminal: PC`、`u-system-name: CPPCC`、`u-login-areaid: 430000`、`content-type: application/json;charset=UTF-8`（站点公开访客凭据）。

## 工作流

### 1. 定位目标节

1. 读 [progress.md](progress.md) 看已读进度，确定下一节（用户点名某节则优先）。
2. 目录缓存 `.lsjz-tmp/catalogue.json` 不存在时，先跑：
   `node .qoder/skills/lsjz-reader/scripts/catalogue.mjs`
   （DFS 阅读顺序列出全部叶子节 id+名称，并写缓存；之后直接读缓存，不重复请求）。
3. 全书结构：前置（封面/扉页/政区图/插彩/凡例/序言/概述/大事记）→ 第一篇地理 … 第二十三篇人物 → 附录 → 编纂人员 → 版权页。特色篇：第六篇锑业、第七篇煤炭电力；毛板船实证在第九篇交通邮电·水路运输（约 283 页）。

### 2. 提取 + 清洗

```bash
node .qoder/skills/lsjz-reader/scripts/fetch-section.mjs <detailId> <输出名>
# 例: node .../fetch-section.mjs 970712 01-地理
```

脚本自动：拉取正文 → 去 `<br>`/重复页眉/杂散页码 → 去 OCR 字间与标点旁空格 → 按句末断段 → 写出带来源注的 `wechat/冷水江市志/<输出名>.md`，原始文本备份到 `.lsjz-tmp/parts/<输出名>.raw.txt`。

### 3. 人工润色（必做，脚本洗不掉错字）

通读清洗稿，修正明显 OCR 错字（历史样例：共产裳→共产党、巳→已、敏旧→破旧），核对乱码句按文意复原；存疑数字/坐标在来源注中注明。完成后在 progress.md 登记一行。

### 4. 公众号版（默认随阅读版一起交付）

阅读版人工润色完成后，默认按 [wechat-template.md](wechat-template.md) 同步改编公众号版，存 `wechat/冷水江市志/公众号-<主题>.md`；用户明确说不要时才跳过。要点：

- 找戏剧冲突做主线（范例一：1994 志书预言两种命运 → 2009 资源枯竭城市应验 → 转型自救；范例二：三百年认错矿 → 90 年发家史），不做志书照搬。
- 1994 年后史实先 WebSearch 核实；文末附资料来源，建议原创声明。
- 文件头「发布说明」「备选标题」区块供用户选择，粘贴进公众号编辑器前删除。
- 文内附「封面提示词」区块：按本篇主题定制一段 AI 绘图提示词（基准风格见模板词库，比例 2.35:1）。**只给提示词，不代生成图**，用户自行去绘图工具生成。

## 交付口径

- 阅读版：`wechat/冷水江市志/NN-节名.md`（NN 为两位阅读序号，00=概述）。
- 公众号版：`wechat/冷水江市志/公众号-<主题>.md`（默认随阅读版交付；封面只给提示词不生成图，在文中「封面提示词」区块）。
- 回复给出文件链接 + 本节内容一句话导读；公众号版附标题选项、封面提示词与发布注意事项。
