# 教资科一材料分析题的半壁江山：**6 个抽屉**锁死"教师职业道德"

> 摘要（填在公众号「简介」栏）：三爱两人一终身不是背条文，是把每条当"抽屉"——具体行为一分类，材料分析题立刻有答案。6 个抽屉 + 3 步法 + 4 顶帽子，一篇打通"背得出口诀却不会做题"。

---

教资科一背到第三天，你会撞上一个非常残酷的现象：

**口诀会背，题目不会做。**

"三爱两人一终身"这六个词刻在脑子里，可材料一摊开——"李老师罚小明站了一节课，还骂他笨猪"——你手抖着只写出**"关爱学生"**四个字，剩下的不知道怎么展开。

问题不在你记不住条文，**在于你把职业道德背成了"课文"，它其实是"分类手册"**。

这一篇我们换个学法：

**把 6 条职业道德，做成 6 个抽屉。做题不是回忆条文，是把每个具体动作丢进对应的抽屉。**

---

**01 一句话搭框架**

《中小学教师职业道德规范》（2008 年修订）6 条，读三遍就能背：

**三爱：** 爱国守法 · 爱岗敬业 · 关爱学生
**两人：** 教书育人 · 为人师表
**一终身：** 终身学习

**但今天不只背这 6 个词，还要给每个词贴一个"抽屉标签"**——考场上你只要做一件事：**把材料里的行为往抽屉里塞。**

| # | 职业道德 | 抽屉标签（一句话解码） |
|---|---------|--------------------|
| ① | 爱国守法 | 政治立场、法律底线 |
| ② | 爱岗敬业 | 勤不勤、走没走心 |
| ③ | 关爱学生 | 学生这个人有没有被当人 |
| ④ | 教书育人 | 怎么教、教出啥、评什么 |
| ⑤ | 为人师表 | 钱 · 礼 · 形象 · 家校同事 |
| ⑥ | 终身学习 | 老师自己在不在学 |

**这张表 = 本篇的灵魂，先背它，再往下读。**

---

**02 六个抽屉，一个个装东西**

每个抽屉都给你三样：**条文原话（防选择题）+ 一句话解码（做题时抓的把手）+ 行为清单表（材料分析题的答案库）。**

---

**① 爱国守法 —— 【基本要求】**

· 热爱祖国，热爱人民，拥护中国共产党，拥护社会主义
· 全面贯彻国家教育方针，**自觉遵守教育法律法规**
· 不得有违背党和国家方针政策的言行

🔑 **解码：** 凡是"国家立场 + 法律底线"的，进这个抽屉。

| 材料里出现这些动作 | 判定 |
|---|---|
| 课堂发表"这国家没救了"等**不当言论 / 传教 / 封建迷信进课堂** | ❌ |
| **把学生赶出教室 / 私自停课 / 长期不让上课**（侵犯受教育权） | ❌ |
| 贯彻教育方针、按课程方案上课、不随意调课占课 | ✅ |

👉 **单选题信号词：** 方针 · 法律 · 政策 · 言论 · 宗教

---

**② 爱岗敬业 —— 【本质要求】**

· 忠诚于人民教育事业，**志存高远，勤恳敬业**
· **甘为人梯，乐于奉献**
· 对工作高度负责，**认真备课上课、认真批改作业、认真辅导学生**
· 不得**敷衍塞责**

🔑 **解码：** 凡是"勤不勤、有没有敷衍"的，进这个抽屉。

| 材料里出现这些动作 | 判定 |
|---|---|
| **常年一份旧教案 / 不备课 / 上课念 PPT / 读课本** | ❌ |
| **作业堆一摞不批 / 让学生代批 / 只写"阅"** | ❌ |
| **迟到早退 / 上完就走 / 只教好班不管差班** | ❌ |
| 四个"认真"齐活；带病坚持上课、义务辅导 | ✅ |

👉 **单选题信号词：** 勤恳 · 奉献 · 敷衍 · 备课 · 批改

⚠️ **和教书育人的分家口诀：爱岗敬业 = 态度；教书育人 = 内容和结果。** 认真上课是"敬"，把学生教明白是"书"。

---

**③ 关爱学生 —— 【灵魂】**（**最高频抽屉**）

· 关心爱护**全体学生**，尊重学生**人格**，**平等公正**对待学生
· 对学生**严慈相济**，做学生**良师益友**
· **保护学生安全，关心学生健康，维护学生权益**
· **不讽刺、挖苦、歧视学生，不体罚或变相体罚学生**

🔑 **解码：** 凡是"学生这个人有没有被尊重 / 被伤害"的，进这个抽屉。

| 材料里出现这些动作 | 判定 | 挂哪一条 |
|---|---|---|
| **只关注优生 / 偏爱前三名 / 只挑好同学回答问题** | ❌ | 违背"全体" |
| **按性别、家庭条件、成绩区别对待** | ❌ | 违背"平等公正" |
| **罚站、罚跑、罚抄 100 遍、掌掴、不给饭吃、罚不许进教室** | ❌ | 体罚 / 变相体罚 |
| **当众念日记、翻书包、搜身、扒衣服** | ❌ | 侵犯人格 + 隐私 |
| **骂"笨猪""你怎么生的""不是学习的料""你一家都是这样"** | ❌ | 讽刺挖苦歧视 |
| **校园欺凌视而不见 / 冬天罚站走廊 / 让学生跑十圈** | ❌ | 未保护安全健康 |
| 严慈相济、既是老师又是朋友、给困难学生垫饭钱 | ✅ | 全体 · 人格 |

👉 **考场送分规则：材料只要出现体罚 / 羞辱 / 歧视 / 侵犯权益 → 必须写关爱学生。漏写直接掉一档。**

---

**④ 教书育人 —— 【天职】**

· 遵循**教育规律**，实施**素质教育**
· **循循善诱，诲人不倦，因材施教**
· 培养学生良好品行，激发学生**创新精神**，促进学生**全面发展**
· **不以分数作为评价学生的唯一标准**

🔑 **解码：** 凡是"教得对不对、评价标准偏不偏"的，进这个抽屉。

| 材料里出现这些动作 | 判定 | 挂哪一条 |
|---|---|---|
| **按分数排座位 / 张榜排名 / 只表扬前三名** | ❌ | 唯分数 |
| **只抓文化课，挤掉音体美 / 不许课外活动** | ❌ | 未全面发展 |
| 对所有学生一套方法，不管差异 | ❌ | 未因材施教 |
| 学生提问 → **"考试不考，别问"** | ❌ | 未激发创新精神 |
| **只教知识、不管品德、不德育渗透** | ❌ | 未培养品行 |
| 一次考差就放弃这个学生 | ❌ | 未诲人不倦 |
| 循循善诱、因材施教、搞项目式学习、带学生做实验 | ✅ | 教育规律 · 创新 |

👉 **考场信号词：** 分数 · 排名 · 音体美 · 品行 · 创新 · 兴趣

---

**⑤ 为人师表 —— 【内在要求】**（**最容易漏答的抽屉**）

· 坚守高尚情操，**知荣明耻，严于律己，以身作则**
· **衣着得体，语言规范，举止文明**
· 关心集体，**团结协作，尊重同事，尊重家长**
· 作风正派，**廉洁奉公**
· **自觉抵制有偿家教，不利用职务之便谋取私利**

🔑 **解码：** 凡是"钱 · 礼 · 形象 · 大人之间的关系"的，进这个抽屉。

| 材料里出现这些动作 | 判定 | 挂哪一条 |
|---|---|---|
| **有偿补课、私自办班收费、"自愿"参加重点班** | ❌ | 抵制有偿家教 |
| **收家长礼品、购物卡、宴请；要求家长请吃饭** | ❌ | 廉洁奉公 |
| **让学生帮自己拿快递 / 接孩子 / 代取咖啡** | ❌ | 利用职务谋私利 |
| **穿拖鞋、浓妆、奇装异服、烟酒、手机进课堂** | ❌ | 衣着 · 举止 |
| **酒后上课 / 课上刷短视频 / 学生面前爆粗口** | ❌ | 语言 · 举止 |
| **和家长吵架 / 办公室拉帮结派 / 和班主任抢学生** | ❌ | 团结协作 · 尊重家长 |
| 以身作则、要求学生做到的自己先做到、拒收礼品、公开透明排座位 | ✅ | 高尚情操 |

👉 **考场送分规则：材料只要出现 补课费 / 家长送礼 / 老师形象问题 / 家校矛盾 / 同事矛盾 → 必须写为人师表。** 大量同学只写"关爱学生"忘了这条，直接少 6 分。

---

**⑥ 终身学习 —— 【发展要求】**

· 崇尚**科学精神**，树立**终身学习理念**
· 拓宽知识视野，更新知识结构
· **潜心钻研业务，勇于探索创新**
· 不断提高专业素养和教育教学水平

🔑 **解码：** 凡是"老师自己在学 vs 停止生长"的，进这个抽屉。

| 材料里出现这些动作 | 判定 |
|---|---|
| **20 年同一份教案、拒绝改 / 按老教材硬教 / 不看新课标** | ❌ |
| **不会用多媒体 / 拒绝学 AI / 拒绝学信息技术** | ❌ |
| **"我这把年纪学不动了" / 不参加教研、不听公开课** | ❌ |
| 50 岁自学 PPT、用 AI 备课、跨学科听课 | ✅ |
| 读研进修、写教育叙事、主持课题、坚持教学反思 | ✅ |

👉 **考场信号词：** 更新 · 视野 · 钻研 · 探索 · 反思 · 进修 · 教研

---

**串记 6 个抽屉：** 政治 · 态度 · 爱生 · 教学 · 廉洁 · 学习——**从国家到课堂到自身，一路向下**。

**03 四顶"帽子"必须分清**（单选题挖坑重灾区）

每年必考一道帽子匹配题，**背下这张表就是送分**：

| 帽子 | 对应条 | 记忆锚点 |
|------|--------|---------|
| **基本要求** | 爱国守法 | 底线，最基础 |
| **本质要求** | 爱岗敬业 | 你**本来就是干这行的** |
| **灵魂** | 关爱学生 | 没有爱就没有教育 |
| **天职** | 教书育人 | 教师这门职业**独有**的使命 |
| **内在要求** | 为人师表 | 由内而外的样子 |
| **发展要求** | 终身学习 | 向前走的能力 |

**最容易混的三个：**
- "灵魂"是**关爱学生**，不是教书育人
- "天职"是**教书育人**，不是爱岗敬业
- "本质要求"是**爱岗敬业**，不是关爱学生

**六字口诀：** **爱基 · 敬本 · 生魂 · 书职 · 表内 · 学展。**

**04 考场三步法：把材料拆开、塞抽屉、挑主打**

这是本篇**做题的核心动作**——不要在脑子里过 6 条全文，按下面三步机械化操作。

**Step 1 · 拆事件**
用铅笔把材料里老师的**每一个具体行为**划线。一段 400 字的材料通常能划出 **3–5 个动作**。

**Step 2 · 分抽屉**
每个动作问一句：**"这是政治、态度、爱生、教学、廉洁、还是学习？"**——归到 6 个抽屉里的某一个。

**Step 3 · 挑主抽屉**
把动作归堆后，哪一堆最多就是主打。**答 2–4 条即可**（不是 6 条全默），主打那条展开写透，其余各写一句带过。

---

**🎯 完整例题走一遍**

**材料（改编）：**
> 李老师是三年级班主任。她常年使用同一份教案上课，从不批改作业，只在作业本上写"阅"。她按上次期中考试成绩排座位，前三名坐中间，最后 5 名被安排到最后一排。小红上课问了一个"超纲"的问题，李老师打断她说："考试不考这个，别问了。"有一次小红作业没交，李老师罚她在走廊站了一节课，还当着全班的面说："你爸妈怎么生出你这种东西。"此外，李老师周末在自己家开小班，收费补课，班里三分之一的学生都参加了。

**Step 1 · 拆事件**（划线）
1. 常年同一份教案 · 从不批改作业（写"阅"）
2. 按分数排座位 · 差生放最后一排
3. 打断学生提问："考试不考，别问了"
4. 罚站一节课 · 当众羞辱"你爸妈怎么生出你这种东西"
5. 周末在家收费补课

**Step 2 · 分抽屉**
| 动作 | 归到哪个抽屉 |
|------|-------------|
| 不备课不批改 | ② 爱岗敬业 |
| 按分数排座位 | ③ 关爱学生（不平等） + ④ 教书育人（唯分数） |
| "考试不考别问" | ④ 教书育人（未激发创新精神） |
| 罚站 + 当众羞辱 | ③ 关爱学生（体罚 + 讽刺挖苦） |
| 收费补课 | ⑤ 为人师表（有偿家教） |

**Step 3 · 挑主抽屉**
归堆结果：**关爱学生 ×2、教书育人 ×2、爱岗敬业 ×1、为人师表 ×1**
→ 主打 **③ 关爱学生** 和 **④ 教书育人**（各展开写），带一句 **② 爱岗敬业** 和 **⑤ 为人师表**。

**⚠️ 注意：** ① 爱国守法 和 ⑥ 终身学习 在这段材料里**没有出现**，不要硬凑。**答对不答全**才是高分关键。

**05 材料分析题万能模板**（写作格式）

**第一步 · 定性**
该老师的做法**符合 / 违背**了《中小学教师职业道德规范》，值得我们学习 / 引以为戒。

**第二步 · 分条论证（套公式）**

> **公式：帽子 + 条文 + 材料复述 + 判断**
>
> **例（关爱学生段）：** "**关爱学生是师德的灵魂。** 规范要求教师关心爱护**全体**学生，尊重学生人格，**平等公正**对待学生，不体罚或变相体罚学生。材料中李老师**因小红未交作业罚其在走廊站一节课**，属于**变相体罚**；**当众辱骂'你爸妈怎么生出你这种东西'**，伤害了学生人格尊严，且按分数排座位，**未平等对待全体学生**。**违背**了关爱学生的要求。"

**第三步 · 结尾**
作为新时代教师，我们应当以该老师为戒 / 为榜样，践行师德规范，做"四有"好老师（有理想信念、有道德情操、有扎实学识、有仁爱之心）。

**⭐ 加分彩蛋：** 结尾顺手带一句 **"四有"好老师 / 雅斯贝尔斯"一棵树摇动另一棵树"**——卷面立刻不一样。

**06 配套记忆：新时代中小学教师职业行为十项准则（2018）**

新规范越来越爱考选择题，简称**"十项准则"**。不用背全文，只要知道它存在 + 记住几个高频关键词：

· 坚定政治方向 · 自觉爱国守法 · 传播优秀文化 · 潜心教书育人
· 关心爱护学生（**严禁体罚、变相体罚、恶意伤害**）
· 加强安全防范
· 坚持言行雅正（**不得与学生发生任何不正当关系**）
· 遵守学术规范
· 秉持公平诚信（**不得在招生、考试、推优、保研中舞弊**）
· 坚守廉洁自律（**不得索要、收受学生及家长财物**）

👉 **判断题、单选题里出现"不正当关系""收受财物""招生考试舞弊"** → 直接锁定**十项准则**，不是 2008 版规范。

**07 教师职业道德范畴**（防御题，只需识概念）

偶尔一道单选题，混个脸熟即可：

· **教师良心** —— 教师内心的道德自律与自我评价
· **教师公正** —— 对学生**平等对待、一视同仁**、赏罚分明
· **教师荣誉** —— 社会对教师职业的道德价值的肯定
· **教师义务** —— 教师对学生、对社会应尽的道德责任

👉 一句话区分：**良心 = 内，公正 = 平，荣誉 = 名，义务 = 责。**

---

**08 三个最容易踩的坑**

**坑一：三个"爱"分不清**

三条带"爱"：**爱**国守法、**爱**岗敬业、关**爱**学生。

· 政治层面 → 爱国守法
· 工作层面 → 爱岗敬业
· 学生层面 → 关爱学生

**坑二：只写"关爱学生"，忘了"为人师表"**

材料里明明写了"有偿补课""收家长购物卡"，很多同学只答关爱学生，**漏了为人师表**，直接掉一档。**只要出现 钱 / 礼 / 补课 / 形象 / 家校矛盾 → 必写为人师表。**

**坑三：把 6 条全默一遍**

材料分析题**不要贪多**。全默一遍不仅浪费时间，还会稀释主打条的分数。**2–4 条 + 展开写透 = 高分；6 条 + 一句带过 = 及格分。**

---

**写在最后**

教资科一背到这里，你已经集齐了 **"三观 + 一德"**：

· 《学生观》—— **两独一发展**
· 《教师观》—— **三者一开放，尊帮反合**
· 《职业道德》—— **三爱两人一终身 + 六个抽屉 + 三步法**
· 下一篇讲《教育观 / 素质教育》—— **提全个创**

**今晚不要背条文，做一件事：随便挑一段材料，把老师每个动作划线、往 6 个抽屉里塞。** 塞得动，28 分你拿走 20 分。

   - 《教资科一材料分析题的半壁江山：**6 个抽屉**锁死"教师职业道德"》
   - 《口诀会背，题不会做？——**三爱两人一终身**的抽屉学习法》

2. **01 节末尾的"六个抽屉"总表**和 **03 节的四顶帽子表**是**转发截图高频页**，建议放文首做长图；mdnice 里表格显示较差，最好截成图片插入
3. **04 节考场三步法**是本篇的核心竞争力，建议整段加**背景色块**（引用样式），并单独做一张**流程图**（拆事件 → 分抽屉 → 挑主打）
4. 本篇和前两篇（学生观、教师观）互相引流，文末"写在最后"处直接放前两篇链接；下一篇《教育观 / 素质教育》口诀 **"提全个创"**——提高国民素质、面向全体、全面发展、创新精神与实践能力
