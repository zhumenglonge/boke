# 教资科一"教师观"背了就忘？8 个字一次记牢，和学生观配套出题

> 摘要（填在公众号「简介」栏）：三者一开放，尊帮反合——一条口诀搞定新课改教师观的所有单选题和材料分析题。和学生观配套背，考前照这篇默写一遍。

---

上一篇刚把「两独一发展」刻进脑子，转身又被**教师观**背刺——

角色四种、行为四种，新旧对照表能拉两页纸。

别慌。教师观其实就 8 个字：

**三者一开放，尊帮反合。**

前者记**角色**，后者记**行为**。写一遍比读十遍管用，这篇建议收藏，睡前默写一次。

---

**01 一句话搭框架**

新课改的教师观分两块，考单选题就是在这 8 个字里做二次确认：

**角色转变 → 三者一开放**

引导者 / 促进者 → 学生身上
建设者 / 开发者 → 课程身上
研究者 → 教学身上
社区型开放教师 → 学校围墙外

**行为转变 → 尊帮反合**

尊 → 对待**师生关系**：尊重、赞赏
帮 → 对待**教学**：帮助、引导
反 → 对待**自我**：反思
合 → 对待**其他教育者**：合作

看到"××老师的做法体现了怎样的教师观"，先在心里过这 8 个字，再对号入座。

---

**02 四种角色，一个个背**

**① 学生学习的引导者、学生发展的促进者**

从"我讲你听"的**知识传授者**，变成"我带你走"的那个人。

· 学习上不直接给答案，**引导**学生自己找到

· 发展上不替学生做主，**促进**他往更好的方向长

👉 题干出现"直接告诉答案""填鸭""包办代替""不给学生思考时间"，选它。

**② 课程的建设者和开发者**

从"教材写啥我念啥"的**忠实执行者**，变成"这堂课我来设计"的那个人。

· 有权、也有责任**开发校本课程**、改编教材

· 用教材教，**不是教教材**

👉 题干出现"照本宣科""只按教参上""老师自己编儿歌 / 做教具 / 引入乡土素材"，选它。

**③ 教育教学的研究者**

从"教书匠"变成"**反思性实践者**"。

· 日常教学里**发现问题 → 分析 → 改进**，就是研究

· 不要求你写论文，要求你带着脑子教书

👉 题干出现"老师坚持写教学日志 / 复盘 / 课题研究 / 把学生当案例研究"，选它。

**④ 社区型开放的教师**

从"学校围墙内的教书先生"，变成"**连接学校和社区**的那个人"。

· 打破学校封闭，把家庭、社区、社会资源引进课堂

· 也把教育服务带到校外

👉 题干出现"请家长进课堂""带学生去社区做调查""联合博物馆 / 派出所"，选它。

**串记：** 引导学生、开发课程、研究教学、开放社区——**从课堂一路扩到社会**。

---

**03 四种行为，一条条背**

行为转变比角色更爱出材料分析题，因为它**落到具体动作**上了。

**① 对待师生关系 → 尊重、赞赏**

· 尊重学生人格，不当众羞辱，不翻旧账

· 赞赏学生的**进步、闪光点、努力**（不是只夸成绩好）

**② 对待教学 → 帮助、引导**

· 学生遇到困难，**帮**他搭梯子，不是替他爬

· 用问题把学生往正确答案**引**，而不是直接给结论

**③ 对待自我 → 反思**

· 波斯纳公式：**经验 + 反思 = 成长**（这个直接背，选择题送分）

· 写教学反思、听自己录的课、复盘一节失败的班会

**④ 对待其他教育者 → 合作**

· 与**班主任 / 科任老师 / 家长 / 社区**协作，不当孤胆英雄

· 学科之间也要横向配合

👉 材料分析题里出现"老师一个人决定""从来不听课""不和班主任沟通""从不写反思"——**违背行为转变**，一分一个。

---

**04 旧 vs 新：一表锁定**

单选题最爱考"以下哪项不属于新课改教师观"，看清"新""旧"再选：

| 维度 | 旧教师观 | 新教师观 |
|------|---------|---------|
| 角色·学生 | 知识的**传授者** | 引导者、**促进者** |
| 角色·课程 | 忠实**执行者** | **建设者、开发者** |
| 角色·教学 | **教书匠** | **研究者** |
| 角色·社会 | 学校围墙内 | **社区型开放教师** |
| 教学 | 强调**服从**、封闭 | 强调**合作、反思** |
| 评价 | 重结果、重甄别 | 重过程、重发展 |

一句话记：**从"教书"走向"育人"，从"孤胆"走向"协同"。**

---

**05 教师观 × 学生观：这对 CP 一起背**

教资科一的材料分析题经常**同时**问"体现了怎样的学生观和教师观"，两个口诀一起用：

| 材料里发生了什么 | 学生观 | 教师观 |
|-----------------|--------|--------|
| 学生一次考砸就被放弃 | 违背"发展的人" | 违背"引导者促进者" |
| 用成人标准苛求小孩 | 违背"独特的人" | 违背"尊重、赞赏" |
| 老师强行改课、不听学生 | 违背"独立意义的人" | 违背"引导者" |
| 老师照本宣科、从不设计 | 学生没被当作主体 | 违背"课程建设者" |
| 老师从不写反思、不听课 | — | 违背"研究者"、违背"反思" |

**看到题干先默念"两独一发展"，再默念"三者一开放尊帮反合"，正反两套一对，答案自己就跳出来。**

---

**06 材料分析题万能模板（教师观版）**

第一步：定性——该老师的做法**符合 / 违背**了新课改背景下的教师观

第二步：**教师是学生学习的引导者和发展的促进者** + 结合材料（例："×老师直接给出答案，没有引导学生思考，违背了这条"）

第三步：**教师是课程的建设者和开发者** + 结合材料

第四步：**教师是教育教学的研究者** + 结合材料

第五步：**教师是社区型的开放教师** + 结合材料

第六步（可加）：**教师行为的转变（尊重、帮助、反思、合作）** + 结合材料

第七步：总结——我们要践行新课改的教师观，做新时代的好老师

**不要 4 条角色 + 4 条行为全默一遍——** 挑材料真正命中的 2–3 条展开，比全背更高分。

---

**07 三个最容易踩的坑**

**坑一：教师是"专业人员"，不是公务员，也不是技术人员**

单选出防御题。教师**是履行教育教学职责的专业人员**，承担**教书育人**使命。看到"公务员""国家干部""技术人员"直接排。

**坑二：主导 ≠ 主体**

**教师是主导，学生是主体。**

材料里"老师是课堂的中心""一切围绕老师转" → 既违背学生观也违背教师观，一起扣分。

**坑三：旧角色不是"错的"，是"不够新"**

老师**也可以**传授知识，但如果他**只会**传授知识、把传授当成全部，那才违背新课改。判断题别一刀切。

今晚睡前默写一遍：

**三者一开放** —— 引导促进、开发建设、研究教学、开放社区

默得出来，学生观 + 教师观 = 材料分析题半壁江山稳了。
